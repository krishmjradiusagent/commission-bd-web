# Commission breakdown · web

Standalone HTML/CSS/JS redesign prototype of the Radius **Commission breakdown** web surface.

## Live preview

https://krishmjradiusagent.github.io/commission-bd-web/

## Local preview

```bash
python3 -m http.server 4187
# then visit http://localhost:4187/
```

## Stack

- Plain HTML / CSS / JS (not React)
- Bundled Radius UI design-system tokens, components, and fonts under `radius/`

## Notes

- Sample / illustrative deal data only
- Light mode
